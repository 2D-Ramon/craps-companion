# Craps companion

Phone-first PWA for live table tracking. Casinos often ban phones at the rail — step away, tap the roll, glance, go back.

**Live:** https://craps-companion-nine.vercel.app  
**GitHub:** https://github.com/2D-Ramon/craps-companion

## Run

```bash
cd web
npm run dev
```

Open https://localhost:3000 on this computer, or the live URL on your phone.

**Add to phone:** open the live site in Safari or Chrome → Share / menu → **Add to Home Screen**.

Data stays on this device until accounts exist.
